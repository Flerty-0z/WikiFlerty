# WikiFlerty

Современная читалка EPUB для Android: всё лучшее из Moon Reader+, ReadEra и PocketBook в одном приложении.

## Что уже есть
- Библиотека с обложками и процентом прочитанного
- Добавление EPUB из памяти телефона или через «Открыть с помощью»
- Чтение с перелистыванием по тапу на краю экрана и свайпом
- Запоминание места в каждой книге
- Боковая панель с разделами: Библиотека, Заметки, Словарь, Синхронизация, Настройки

## В планах
- Заметки и выделения
- Словарь с ИИ-объяснениями слов (через API, с выбором модели)
- Синхронизация с Google Drive и Dropbox, экспорт и импорт всех данных
- Настройки шрифтов, тем, отступов и жестов

## Как получить APK
Каждое изменение в ветке `main` собирается на GitHub автоматически.
Готовый файл лежит в разделе **Releases** репозитория.

## Технологии
Kotlin, Jetpack Compose, [Readium Kotlin Toolkit](https://github.com/readium/kotlin-toolkit) для отображения EPUB.
