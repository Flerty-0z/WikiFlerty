# WikiFlerty

Читалка EPUB для Android с ИИ-словарём, озвучкой и карточками для запоминания слов.

## Возможности

**Чтение**
- Страницы или лента, анимации листания, жесты и кнопки громкости
- 20+ шрифтов, темы страницы, интервалы, поля, колонки на планшете
- Оглавление, флажок прогресса, полноэкранный режим, яркость свайпом

**Заметки и словарь**
- Выделения цветом и заметки с редактируемой палитрой
- ИИ-объяснения, определения и перевод выделенного текста: Claude, ChatGPT, Gemini, DeepSeek, Grok, Mistral, Qwen, Kimi, GLM, Groq, OpenRouter или любой сервис с OpenAI-совместимым API
- Один ключ — приложение само определяет, чья это нейросеть
- Личный словарь с цитатой и ссылкой на место в книге
- Карточки с интервальным повторением

**Чтение вслух**
- Любой установленный синтезатор речи и голос
- Подсветка текущего предложения, листание за голосом
- Работа с выключенным экраном, управление из уведомления, таймер сна

**Библиотека и статистика**
- Статусы, избранное, полки, поиск, сортировка, сетка или список
- Время чтения, скорость, серии дней, цель на день

**Оформление**
- Шесть готовых шаблонов, свой акцентный цвет, шрифт интерфейса
- Фон-картинка или видео

**Данные**
- Экспорт и импорт всех данных одним файлом, с книгами или без

## Сборка

Каждое изменение в `main` собирается автоматически, готовый APK публикуется в разделе **Releases**.

## Технологии

Kotlin, Jetpack Compose, [Readium Kotlin Toolkit](https://github.com/readium/kotlin-toolkit), Media3.
